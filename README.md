
# Crash Simulator

This is a C++ program that simulates different types of crashes including:
- Memory leaks
- Null pointer dereferencing
- Thread deadlocks

## How to run
1. Clone the repository:
   ```
   git clone https://github.com/yourusername/crash-simulator.git
   ```

2. Compile the code:
   ```
   g++ -o crash_simulator main.cpp -std=c++11
   ```

3. Run the executable:
   ```
   ./crash_simulator
   ```
